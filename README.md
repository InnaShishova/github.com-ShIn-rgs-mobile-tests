# Mobile UI Automation Project

Проект мобильной автоматизации тестирования приложения Wikipedia для Android.

## Technology Stack

- Java 17
- JUnit 5
- Appium
- BrowserStack
- Owner
- Allure Report
- Gradle
- Git
- GitHub

## Implemented Tests

- Поиск статьи в Wikipedia
- Открытие статьи из результатов поиска
- Проверка открытия экрана поиска
